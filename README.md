# ניהול תיקים משפטיים על המזלג ⚖️

אפליקציית ווב מהירה מאוד, נקייה ובעברית מלאה מימין לשמאל (RTL) לניהול תיקים משפטיים ותעדוף יומי (**חדל"פ, חברות וגבייה**), המותאמת לעבודה חלקה עם **1,000+ תיקים** ללא אחסון קבצים כבדים — רק נתוני ליבה, תרשומות שיחה, פעולות, תזכורות ומועדי דיון.

---

## ✨ יכולות המערכת
1. **מצב עבודה מיידי ללא מפתחות (LocalStorage Demo Mode):**
   - אם משתני הסביבה של Supabase טרם הוגדרו, המערכת פועלת אוטומטית במצב הדגמה מקומי מלא בדפדפן, טעונה מראש ב-5 תיקי דוגמה ריאליסטיים בעברית ויומן תרשומות.
2. **לוח בקרה ותעדוף יומי (`/`):**
   - **4 כרטיסי KPI עליונים (לחיצים לסינון מהיר):** סה"כ תיקים פעילים, דחוף / להיום או באיחור, דיונים ומועדים ב-7 הימים הקרובים, ותיקים בהסדר תשלומים.
   - **רצועת "תזכורות קופצות / דחופים":** מציגה בראש הדף רק תיקים באיחור או עם תאריך יעד ב-7 הימים הקרובים, עם כפתור **"בוצע"** בקליק אחד (שרושם אוטומטית ביומן התיק ומנקה את תאריך היעד).
   - **חיפוש וסינון בזמן אמת:** סינון מיידי לפי שם חייב/חברה, ת"ז/ח"פ, מספר תיק, עירייה, הערות, סוג הליך (`חדל"פ`, `חברות`, `גבייה`) ותגיות (`חברה משכנת`, `עיזבון`, `בהסדר`, `מנהל מיוחד/מפרק`, `ייצוג נושה`).
3. **כרטיס תיק נפתח מהצד (Slide-Over Drawer ללא מעבר דף):**
   - לחיצה על כל שורת תיק פותחת מגירה צדדית חלקה מימין.
   - **טופס מהיר בראש המגירה:** הוספת `תרשומת שיחה` / `פעולה שבוצעה` / `החלטת ביהמ"ש` / `פעולה נדרשת` + עדכון הפעולה הבאה ותאריך היעד של התיק בקליק אחד.
   - **פיד כרונולוגי מלא** של כל ההיסטוריה והתרשומות בתיק.
   - **עריכה במקום** של כל שדות התיק.
4. **ייבוא וייצוא CSV (אקסל / Google Sheets):**
   - ייבוא רשימת תיקים קיימת מקובץ CSV בלחיצה אחת (כולל הורדת תבנית CSV מוכנה בעברית), וייצוא הטבלה לאקסל עם תמיכה מלאה בעברית (UTF-8 BOM).

## ☁️ חיבור ל-Supabase והעלאה לענן (GitHub + Vercel / Render)

### שלב א': הגדרת מסד הנתונים ב-Supabase
1. צור פרויקט חדש חינמי ב-[Supabase](https://supabase.com).
2. בתפריט הצד ב-Supabase היכנס ל-**SQL Editor**, העתק את כל תוכן הקובץ [`supabase/schema.sql`](./supabase/schema.sql) והרץ אותו (**Run**).
   - פעולה זו תיצור את הטבלאות `cases` ו-`case_logs`, אינדקסים מהירים ל-1,000+ תיקים, והגדרות אבטחה (`RLS`) כך שרק משתמש מחובר יכול לצפות ולערוך נתונים.
3. בתפריט **Authentication -> Providers -> Email**, ודא שהתחברות עם Email & Password פעילה, וצור לעצמך משתמש בלשונית **Users** (או הירשם ישירות דרך דף `/login`).
4. העתק מ-**Project Settings -> API** את:
   - `Project URL`
   - `anon public key`
5. צור קובץ `.env.local` בתיקיית הפרויקט (לפי התבנית ב-[`.env.example`](./.env.example)):
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-public-key
   ```

### שלב ב': העלאה ל-GitHub ופריסה ב-Vercel או Render
1. העלה את הקוד ל-Repository פרטי ב-GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Legal Case Tracker RTL"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
2. היכנס ל-[Vercel](https://vercel.com) (או Render), בחר **Add New Project** וחבר את ה-Repository מ-GitHub.
3. תחת **Environment Variables**, הוסף את שני המשתנים:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. לחץ **Deploy** — תוך דקה תקבל קישור קבוע ומאובטח (`https://...vercel.app`) שממנו תוכל להתחבר עם מייל וסיסמה מכל מחשב או נייד.
